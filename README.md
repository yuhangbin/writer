Writer

这是一个写作AI Agent网站，帮助用户快速生成想要的文章
# MVP

Workspace: 每个工作区互相独立,让工作的上下文聚焦

Workspace Settings: 配置工作区 1. 参考示例 2. 目标读者

Creative Zone: 文章生成，编辑，导出的区域


## 技术栈

Framework: Next.js 14+ (App Router)
UI: Tailwind CSS + Shadcn/UI (Tabs, Dialog, Select, Button, Card, Sidebar)
Editor: Tiptap (集成基础格式：标题、加粗、列表)
Icons: Lucide React
Persistence: 初始版本使用 localStorage 进行持久化。
CodeStyle: 使用TypeScript，禁止使用any
